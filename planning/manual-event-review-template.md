# LOCAL GUIDE — イベント掲載候補の手動確認票（未公開）

作成日: 2026-10-15。今後の掲載候補を整理するための書式です。**実イベントの追加や公開ではありません。**

| 確認する項目 | 記録時のルール |
|---|---|
| 発見元 | 地域メディア・RSS等の記事URL。**掲載内容の一次情報とは区別** |
| 主催者の公式案内 | 主催者自身のイベントURL。ない場合は掲載保留 |
| 市町と会場 | 加古川・明石・姫路・高砂・播磨・稲美の確認済み所在地 |
| 開始日・終了日 | 主催者公式の情報どおり。日付のみなら時刻を推測しない |
| 料金 | 無料・有料・条件付き・不明。無料は根拠確認必須 |
| 対象年齢・定員・予約 | 整理券、会員登録、アンケート、先着組数等も個別に確認 |
| 設備・アクセシビリティ | 駐車場、雨天、バリアフリー、手帳割引などは公式で確認できた項目だけ |
| 中止・変更 | 最終の公式確認日時をAsia/Tokyoで記録 |
| 出典の利用許可 | リンク方針と、本文/画像転載・HTML/RSS自動取得の許可を区別 |
| 編集判定 | 未確認 / 一次情報検証済み / 保留 / 差戻し |

## 掲載までの流れ
1. RSS公開日をイベント開催日に流用しない。地域記事の説明文・画像をコピーしない。
2. 主催者の公式ページで会場・開催回・料金・参加条件を別々に確認する。
3. データ利用条件・一次情報源の権利を検証してから、承認済みの `config/sources.json` に紐づける。
4. `schemas/events.schema.json` に沿ってデータを準備し、保留が必要なら `review_hold=true` で掲載対象から外す。
5. `python -m localguide validate`、`python -m scripts.cloudflare_build`、`python -m scripts.release_readiness` で確認する。
6. 新規データの掲載、Cloudflare初回公開、SEO登録はそれぞれ別途レビューする。

**例:** 「観覧無料」の表記から、同じ会場のワークショップまで全部無料と判断しない。主催者への確認なしに対象年齢や定員を創作しない。
